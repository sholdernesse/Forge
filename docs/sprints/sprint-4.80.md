# Sprint 4.80 — Movement Library Simplification

## Goal

Remove obsolete visual-system controls after completing paired guidance for every planner movement.

## Delivered

- Removed the `All guides` versus `AI characters` filter because every active guide now uses the owned AI-character WebP system.
- Retained one full-width search for movement names, primary muscles, and secondary muscles.
- Clarified that all results include both form and muscle views and that opening a guide never changes the user's program.
- Corrected the product plan's stale core-and-mobility status after the Sprint 4.79 catalog completion.

## Product constraint

No capability, route, stored state, or architecture was added. The change removes a duplicate decision and preserves the existing contextual entry point beside the workout.

## Acceptance

- Movement Library opens directly to the complete searchable catalog.
- Search and empty-result behavior remain unchanged.
- Desktop and phone layouts no longer reserve space for a redundant filter group.
